# texel-coverage

## 0.3.0

### Minor Changes

- 9060e4f: Bake to Suggested UVs: bakes every texture into the suggested layout (normal maps included), promotes it and switches the materials; Revert Bake and Ctrl+Z go back. New `bake` / `revert-bake` commands. Ratio and Required buttons now toggle the view off and restore the previous shading.
- e56fc64: Suggest UVs packs far tighter, for any island shape: faces the export cull deletes get no texels, faces long enough to set the texture size are split, big islands are cut into grid chunks that each get their own density, Blender's outline packer places them, and the texture is the smallest power of two that holds the screen's 95th percentile within the new Size Tolerance (default 0.85). The report gains `culled` and `use` (texels the camera asks for over the texture's texels). On the test scene, texture memory went from 243 MB to 64 MB.
- 9487f08: First versioned release. Clearer Ratio and Required colours with swatch legends in the sidebar, viewport and UV editor; `tc_crop_*` camera properties removed; command line accepts commands after options; fixed the sidebar status line.

### Patch Changes

- fa1099f: Bake to Suggested UVs no longer runs out of memory on big scenes: textures are never baked larger than their source, Cycles only sees the objects being baked, and each image is saved and freed right after its bake.
- 52098a3: No more duplicated work between stages. The geometry key is world-space for plain static meshes, so renaming, splitting or joining objects keeps the stored analysis and cull valid; `core.restamp()` lets tools carry them over visibility-neutral edits (a join moves vertices by float noise). Identical camera moments are evaluated once in analysis, cull and the pixel pass. Suggest UVs computes the cull once and the export reuses it (a full run went from ~41 to ~23 min, export from 15 min to 8 s).
- ef89212: Cull panel shows the active object's cull status, faces kept and per-object overrides, editable in place.
- 3e0f91c: The Export button and CLI export now include the analysed cameras in the GLB (new Include Cameras setting, on by default), so viewers can look through the render's point of view. Also fixes Camera: Selected exports, which lost the camera selection when exporting a collection.
- 52098a3: Suggest UVs packs faster: the texture size is estimated from the islands' real area and the concave packer runs once (at most one correction) instead of once per candidate size, and sliver chunks are merged into their neighbours. Same sizes and layout quality. Also fixes a crash on image names longer than 63 characters (planned sizes are stored as JSON).
- ef93798: Texel actions switch to Object Mode first, so Analyze no longer fails when a mesh is in Edit Mode.
- b05258c: Second review: bake skips textures it can't convert safely (alpha, transformed coordinates, mixed normal/colour use, several UV maps) and only switches a layout when every texture on it converts, with rollback on failure; linked copies are sized from the largest copy and can be selected individually; cull and verify use private temp folders, always restore hidden objects, and keep the cull modifier's stack position.
- 5356d94: Review fixes. The cache keys now bind each face's stored analysis and cull result to its geometry and include every object's transparency, so swapping identical meshes or making a wall see-through invalidates them. Shape keys, constraints and NLA count as motion. Camera moments with different clipping ranges are no longer merged. Triangles fully behind the camera no longer stop the analysis. Suggest UVs: locked islands are respected on the first run, an object with two UV maps on one image uses shelf packing, the fallback stores the size it really used, meshes with modifiers are never split, and culled faces only lose their texels when the optimized export will cull them. Include Cameras now decides both the panel Export button and the CLI.
- ec2f6d9: Review fixes: linked duplicates no longer overwrite each other's cull, analysis or UV backups; a cull with no cameras refuses instead of removing every face; faces crossing the frame with no corner inside count as seen; rectangular textures and Mapping-node scales are measured correctly; camera selection is part of the cache fingerprint; `export --collection` optimizes what it exports; failed CLI actions exit 1; zero-gap UV packing can't hang. New: Compress with Chopper option in the sidebar and glTF dialog.
- e56fc64: Analysis, cull and bake fixes found on a full test scene: glass and other transparent objects no longer hide what's behind them, faces that reach behind the camera are clipped and measured instead of counted as unseen, and objects hidden from rendering can still be baked.
